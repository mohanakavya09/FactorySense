# FactorySense

### Contactless Machine Health Monitoring System Using Wi-Fi Radar

FactorySense is a proposed contactless machine-health monitoring system that explores the use of Wi-Fi radar and signal processing to monitor machine conditions without requiring physical contact with the machinery.

The project was developed and presented as part of the MSME Hackathon 6.0.

---

## 🎯 Project Overview

Traditional machine-health monitoring can involve physical sensors attached directly to machines.

FactorySense explores a contactless approach using Wi-Fi-based sensing to capture changes associated with machine activity and health.

The project focuses on:

- Contactless machine monitoring
- Wi-Fi radar / Wi-Fi sensing
- Signal processing
- Machine-health analysis
- Future integration of vibration data
- AI-based fault prediction as a future direction

---

## 💡 Proposed Concept

The core idea is to use Wi-Fi signals as a sensing medium.

Changes in the environment and machine activity can influence the received wireless signal. By processing and analysing these signal variations, machine behaviour can potentially be monitored without physically attaching a sensor to the machine.
